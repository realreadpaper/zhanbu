☯️ 六爻占卜（高岛易断）

随机起卦 蓍草法 / 铜钱法 以《高岛易断》为断法依据

1.1 概述

六爻占卜是最传统的易学占卜方法之一。通过随机方式生成六条爻线（阴阳），组成一个六十四卦中的卦象，再根据动爻产生变卦。本系统实现了两种起卦方法，并结合日本明治时代易学大师高岛吞象的《高岛易断》原文进行 AI 解读。

1.2 起卦方法

蓍草揲蓍法（Yarrow Stalk）

模拟传统蓍草揲蓍的四营三变过程，生成 0-15 的随机数（共 16 份），映射为爻值。概率分布符合历史文献记载的不对称分布：

随机数爻值类型是否动爻概率
09（老阳）阳爻 ⚊✅ 是1/16 = 6.25%
1 ~ 78（少阴）阴爻 ⚋❌ 否7/16 = 43.75%
8 ~ 127（少阳）阳爻 ⚊❌ 否5/16 = 31.25%
13 ~ 156（老阴）阴爻 ⚋✅ 是3/16 = 18.75%
蓍草法的核心特征：老阴（6）出现概率是老阳（9）的 3 倍，这与传统揲蓍法的数学推导一致。

铜钱法（Coin）

模拟三枚铜钱同时投掷，以正面（阳）朝上的数量决定爻值。概率分布对称：

阳面数爻值类型是否动爻概率
39（老阳）阳爻 ⚊✅ 是1/8 = 12.5%
28（少阴）阴爻 ⚋❌ 否3/8 = 37.5%
17（少阳）阳爻 ⚊❌ 否3/8 = 37.5%
06（老阴）阴爻 ⚋✅ 是1/8 = 12.5%

1.3 计算流程

  1. 生成六爻 — 从初爻（底部）到上爻（顶部），依次生成 6 条爻线，每条包含值（6/7/8/9）、类型、是否动爻、符号（⚊/⚋）。
  2. 编码为二进制 — 7（少阳）和 9（老阳）映射为 1，6（老阴）和 8（少阴）映射为 0。从上爻到初爻拼成 6 位二进制串，如 "111010"。
  3. 查找本卦 — 用二进制串在 64 卦数据库中查找对应的卦象（含卦名、卦辞、象辞、六爻爻辞等完整信息）。
  4. 确定动爻 — 值为 9（老阳）或 6（老阴）的爻为动爻。
  5. 计算变卦 — 将每条动爻阴阳互变（9→8, 6→7），重新编码为二进制串，查找变卦。
  6. 检索书中证据 — 从《高岛易断》原文中检索与当前卦象、动爻相关的段落，作为 AI 解读的依据。

🌸 梅花易数

时间起卦 数字起卦 师承邵雍一脉，以数成象

2.1 概述

梅花易数由北宋邵雍（邵康节）所创，核心思想是"以数成象"——万物皆可起卦。本系统实现两种起卦方式：时间起卦（使用农历）和数字起卦。断法重点在于本卦、互卦、变卦与体用生克关系。

取模基数为 8，余数 0 视为 8（坤）。

2.3 时间起卦算法

使用农历的年、月、日、时进行计算。年数和时数按地支序号取值：

地支子丑寅卯辰巳午未申酉戌亥
序数123456789101112
上卦 = (年数 + 农历月 + 农历日) % 8　→　余 0 取 8（坤）
下卦 = (年数 + 农历月 + 农历日 + 时辰数) % 8　→　余 0 取 8（坤）
动爻 = (年数 + 农历月 + 农历日 + 时辰数) % 6　→　余 0 取 6（上爻）
经典验证：辰年十二月十七日申时 → 5+12+17=34, 34%8=2(兑), 34+9=43, 43%8=3(离), 43%6=1(初爻)
→ 本卦：兑上离下 = 泽火革，初爻动，变卦：兑上艮下 = 泽山咸

2.4 数字起卦算法

用户输入任意数字（至少 2 个），系统按以下规则计算：

上卦 = 前半部分数字之和 % 8　→　余 0 取 8
下卦 = 全部数字之和 % 8　→　余 0 取 8
动爻 = 全部数字之和 % 6　→　余 0 取 6

例如输入 12 34：上卦 = 12%8 = 4(震)，下卦 = 46%8 = 6(坎)，动爻 = 46%6 = 4(四爻)。

2.5 互卦计算

互卦取本卦六爻中的中间四爻重新组合：

互卦下卦 = 本卦第 2、3、4 爻
互卦上卦 = 本卦第 3、4、5 爻

每卦展开为 3 爻（从下到上），例如离 = 阳/阴/阳，兑 = 阳/阳/阴。

2.6 变卦计算

将动爻所在位置的爻阴阳互变（阳变阴、阴变阳），重新组成上下卦。

2.7 体用生克分析

梅花易数的核心断法——体用关系：

  • 体卦 — 不动的卦（静卦）
  • 用卦 — 动爻所在的卦

判断规则：动爻在下卦（1~3爻），则下卦为用、上卦为体；动爻在上卦（4~6爻），则上卦为用、下卦为体。

体用关系五行关系含义吉凶
比和体用同元素平稳，无大碍平
用生体用卦五行生体卦助力大，易成吉
体生用体卦五行生用卦耗泄较多，需付出凶
用克体用卦五行克体卦阻力大，需谨慎凶
体克用体卦五行克用卦可以掌控，但需主动吉

🎴 塔罗牌

随机抽牌 Fisher-Yates 洗牌 78 张牌 · 4 种牌阵

3.1 概述

塔罗牌是西方占卜体系中最具代表性的工具，共 78 张牌，分为大阿尔卡纳（22 张）和小阿尔卡纳（56 张，分四花色各 14 张）。本系统从数据库加载全部牌面信息，通过随机洗牌和抽牌完成占卜。

3.2 牌面数据库

每张牌包含以下信息：

字段说明
Name / NameEn中文名 / 英文名
Typemajor（大阿尔卡纳）/ minor（小阿尔卡纳）
Suit花色：wands(权杖) / cups(圣杯) / swords(宝剑) / pentacles(星币)
KeywordsUp / KeywordsDown正位 / 逆位关键词
MeaningUp / MeaningDown正位 / 逆位完整释义

3.3 牌阵类型

牌阵牌数位置含义
单牌（single）1核心信息
三牌阵（three）3过去 · 现在 · 未来
凯尔特十字（celtic）10现况、挑战、潜意识、过去、意识、近未来、自我认知、外在环境、希望恐惧、最终结果
爱情十字（love）5你的状态、对方状态、关系挑战、你的期望、关系方向

3.4 算法流程

  1. 加载牌库 — 从数据库读取全部 78 张牌。
  2. Fisher-Yates 洗牌 — 对整副牌进行标准 Fisher-Yates 随机置换，保证每种排列等概率出现。
  3. 抽取牌面 — 取洗牌后的前 N 张（N = 牌阵所需牌数）。
  4. 判定正逆位 — 每张牌以 50% 概率判定为正位（upright）或逆位（reversed）。
  5. 组合结果 — 将每张牌与牌阵位置名称配对。
系统使用数据库存储牌面数据而非嵌入式 JSON，便于后续扩展自定义牌组。牌面抽出后不从牌库移除（实际洗牌后概率极低重复）。

📋 八字排盘（四柱命理）

确定性算法 无随机性 以出生年月日时排出四柱

4.1 概述

八字命理（又称四柱推命）是中国传统命理学的核心方法。根据出生的年、月、日、时各排出一组天干地支（共八个字），再分析五行分布、日主强弱、十神关系来推断命理结构。

4.2 基础数据

天干（10 个）

天干甲乙丙丁戊己庚辛壬癸
五行木火土金水

地支（12 个）

地支子丑寅卯辰巳午未申酉戌亥
五行水土木木土火火土金金土水

4.3 四柱排法

年柱

天干索引 = (年份 - 4) % 10
地支索引 = (年份 - 4) % 12

以公元 4 年为甲子年基准。

月柱

地支固定：正月=寅、二月=卯...十二月=丑。天干由年干推算，遵循"甲己之年丙作首"口诀：

年干甲/己乙/庚丙/辛丁/壬戊/癸
正月天干起始丙(2)戊(4)庚(6)壬(8)甲(0)

日柱

使用儒略日数（JDN）计算。以 1900-01-01 = 庚子日（甲子序 36）为参考点：

甲子序 = (36 + 目标JDN - 参考JDN) % 60
天干 = 甲子序 % 10　　地支 = 甲子序 % 12

时柱

地支：23-1点=子时，1-3点=丑时... 时干由日干推算，遵循"甲己还加甲"口诀。

4.4 五行分析

  1. 统计四柱八字（4 天干 + 4 地支）中各五行出现次数
  2. 找出最强和最弱的五行
  3. 确定日主（日柱天干）的五行
  4. 判断日主强弱：出现 ≥3 次 = 偏强，≤1 次 = 偏弱，否则中和
  5. 推导用神：日主偏强取克我之五行，日主偏弱取生我之五行
  6. 忌神为用神的对立面

4.5 十神分析

将其他天干与日主对比，确定五行生克关系：

关系含义十神
同我与日主同五行比肩
我生日主所生之五行食神
生我生助日主之五行偏印
我克日主所克之五行偏财
克我克制日主之五行偏官

⭐ 星座运势

确定性算法 SHA-256 种子 12 星座 · 3 种周期

5.1 概述

星座运势模块为 12 个西方星座生成每日、每周、每月的运势评分和解读文本。系统采用确定性算法——相同星座 + 日期 + 周期始终产生相同结果，确保用户多次查询的一致性。

5.3 算法流程

Step 1：日期归一化

  • 每日：直接使用日期字符串 "2006-01-02"
  • 每周：转为 ISO 周字符串 "2006-W02"，同周内所有天产生相同结果
  • 每月：转为年月 "2006-01"

Step 2：确定性种子生成

seed = SHA-256( 星座名 + 归一化日期 + 周期 ) 的前 8 字节 → uint64

同一个 星座+日期+周期 组合永远产生相同的种子值。

Step 3：五维评分

从种子中按不同偏移量提取 5 个 1~5 的整数评分：综合、爱情、事业、财运、健康。

score = min + ( (seed >> (offset*8)) XOR (seed >> 32) ) & 0xFFFFFFFF ) % (max - min + 1)

Step 4：幸运元素

  • 幸运数字：从种子偏移 5 提取，范围 1~9
  • 幸运颜色：从种子偏移 6 映射到 12 色池（红、橙、黄、绿、蓝、紫、粉、白、金、银、青、棕）

Step 5：等级映射与模板选取

分数等级
1~2low（低迷）
3mid（平稳）
4~5high（旺盛）

从预置的 JSON 模板文件中，按 星座_维度_等级 键选取对应的解读文本。模板覆盖 12 星座 × 3 周期 × 5 维度 × 3 等级 = 每周期 540 条模板。

6.1 架构共性

五种方式均遵循统一的三层架构：

  1. Service 层 — 纯算法服务，输入参数 → 计算 → 输出结构化结果
  2. Handler 层 — HTTP 接口，参数校验 + 调用 Service + 保存 DivinationRecord
  3. AI 层 — 专用 prompt 模板，将结构化结果传给 AI 进行自然语言解读

所有占卜结果统一存储在 DivinationRecord 表中（type + question + result JSON + ai_reading），支持历史记录查看和聊天模式多轮对话。
