🎯 占卜方式选择器设计

📍
位置固定
位于导航栏下方，始终可见，方便随时切换
🎨
视觉反馈
选中状态使用渐变背景 + 边框高亮 + 加粗文字
↔️
横向滚动
选项过多时支持横向滑动，隐藏滚动条
🔄
切换行为
切换后更新欢迎卡片、快捷提问和输入框 placeholder

💬 对话状态设计

🎴
选择器收起
进入对话后，选择器变小但保持可见，方便切换
📝
头部信息
显示当前占卜方式和牌阵信息
⚡
快捷提问
对话中显示通用快捷提问（详细解读、建议等）
🔄
切换占卜方式
切换后开始新的对话，历史对话保留可查看

🔄 切换占卜方式的行为

1. 用户点击其他占卜方式
2. 弹窗确认：「切换将开始新对话？」
3. 确认后 → 清空当前聊天
4. 显示新的欢迎卡片
5. 更新快捷提问和输入框
* 历史对话保留在「历史记录」中
